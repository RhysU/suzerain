Compute the one-sided hyperbolic tangent stretching function.

The function has domain \(\left[0,L\right]\), range \(\left[0,1\right]\) and is given by

\[ s\left(x\right) = 1 + \frac{ \mbox{tanh}\left[\delta\left(x/L-1\right)\right] }{ \mbox{tanh}\left[\delta\right] } \]

with the limiting \(\delta\to{}0\) result being simply \(x/L\).

Parameters
deltaThe stretching factor \(\delta\in\left[0,\infty\right)\)
LThe domain endpoint \(L\)
xThe desired evaluation point \(x\in\left[0,L\right]\)
Returns
The one-sided hyperbolic tangent stretching function evaluated for the given parameters.

Find a stretching factor \(\delta\) so that \(s\left(x_{\mbox{crit}}\right) \approx{} s_{\mbox{crit}}\).

Parameters
[in]LThe domain endpoint \(L\)
[in]x_critThe desired evaluation point \(x_{\mbox{crit}}\in\left[0,L\right]\)
[in]s_critThe desired evaluation value \(s_{\mbox{crit}}\in\left[0,1\right]\)
[in]epsabsThe absolute tolerance criteria for stopping the iterative process per gsl_root_test_residual()
[in]maxiterThe maximum number of iterations to attempt
[out]deltaAn approximation to the necessary stretching factor \(\delta\) to solve the problem. When SUZERAIN_SUCCESS is returned, this meets the given tolerance. When SUZERAIN_EMAXITER is returned, this is a best guess but does not meet the tolerance. For any other return value, delta is undefined.
Returns
SUZERAIN_SUCCESS (zero) on success. Returns SUZERAIN_EMAXITER if the maximum number of iterations was reached without meeting the given tolerance requirement. On any other error, calls suzerain_error() and returns one of suzerain_error_status.

suzerain_htstretch1() for the form of \(s\left(x\right)\).

Compute the two-sided hyperbolic tangent stretching function.

The function has domain \(\left[0,L\right]\), range \(\left[0,1\right]\) and is given by

\[ u\left(x\right) = \frac{1}{2}\left(1 + \frac{ \mbox{tanh}\left[\delta\left(x/L-1/2\right)\right] }{ \mbox{tanh}\left[\delta/2\right] }\right) \]

with the limiting \(\delta\to{}0\) result being simply \(x/L\).

Parameters
deltaThe stretching factor \(\delta\in\left[0,\infty\right)\)
LThe domain endpoint \(L\)
xThe desired evaluation point \(x\in\left[0,L\right]\)
Returns
The two-sided hyperbolic tangent stretching function evaluated for the given parameters.
