Detailed Description

Higher-level logic build atop the GSL B-spline routines.

Provides higher-level logic built atop the GNU Scientific Library (GSL) B-spline routines.

Many of these routines can (and should) be refactored and submitted upstream to the GSL.

Multiple threads may call these routines simultaneously provided that each thread has its own workspace instance. The behavior is undefined if two threads simultaneously share a workspace.

int suzerain_bspline_linear_combination ( const size_t  nderiv,
const double *  coeffs,
const size_t  npoints,
const double *  points,
double *  values,
const size_t  ldvalues,
gsl_matrix *  dB,
gsl_bspline_workspace *  w 
)

Evaluate a function and its derivatives based upon a linear combination of the basis functions.

At each point in points, evaluate the function and its derivatives determined from a linear combination of the supplied real-valued coeffs times the B-spline basis functions at point. Derivatives 0 through nderiv (inclusive) are computed and stored as columns within values. That is,

\[ \mbox{values}\left[i + k\,\mbox{ldvalues}\right] = \frac{d^k}{dx^k} \sum_{j=0}^{\mbox{ndof}} \mbox{coeffs}_{j}\,B_{j}(\mbox{points}_{i}) \]

for \( i\in\left\{0,\ldots,\mbox{npoints}\right\} \), \( k\in\left\{0,\ldots,\mbox{nderiv}\right\} \), \(\mbox{ndof} = \) w->n, and B-spline basis functions \( B_{j} \). If only a single derivative is desired, passing 0 to ldvalues will cause only that single derivative to be written in the first column of values.

Note
It is more efficient to compute a function and its derivatives simultaneously than to request each derivative separately. This is due to the recurrence relationship used to compute B-spline derivatives.
Parameters
[in]nderivMaximum requested derivative. This may be higher than the number of derivatives requested in suzerain_bspline_alloc().
[in]coeffsReal-valued expansion coefficients for a function in terms of the B-spline basis. Must be of length w->n.
[in]npointsNumber of evaluation points.
[in]pointsPoints at which to evaluate the function.
[out]valuesMatrix of real values resulting from evaluating the function and its derivatives. Matrix dimensions are w->n by nderiv if ldvalues >= w->n. If ldvalues is zero, only a single column is returned in values.
[in]ldvaluesLeading dimension of the output matrix values measured as real-valued strides.
[in]dBTemporary storage to use of size w->k by no less than nderiv + 1.
[in]wWorkspace to use.
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status.
See also
suzerain_bspline_linear_combination_complex() for a way to evaluate a function and its derivatives when the coefficients are complex-valued.

Using the function specified by B-spline coefficients coeffs for basis w, find the location at which the function's nderiv derivative crosses value within the region [lower, upper].

The crossing must be known a priori to exist by the intermediate value theorem. If multiple crossings exist, it is undefined which is returned. Convergence is reached whenever [lower, upper] satisfy the criteria set forth in gsl_root_test_interval using epsabs and epsrel.

Parameters
[in]nderivDerivative of interest This may be higher than the number of derivatives requested in suzerain_bspline_alloc().
[in]coeffsReal-valued expansion coefficients for the function with respect to B-spline basis. Must be of length w->n.
[in]valueThe function value at which a crossing is sought.
[in,out]lowerOn entry, the lower edge of the range in which a crossing is sought. On exit, the active lower bound in the search.
[in,out]upperOn entry, the upper edge of the range in which a crossing is sought. On exit, the active upper bound in the search.
[in]maxiterMaximum number of iterations to attempt.
[in]epsabsAbsolute error bound used as a stopping criterion.
[in]epsrelRelative error bound used as a stopping criterion.
[out]locationLocation at which a crossing is found.
[in]dBTemporary storage to use of size w->k by no less than nderiv + 1.
[in]wWorkspace to use.
Returns
SUZERAIN_SUCCESS on success and returns the answer in *location. If convergence is slow, SUZERAIN_CONTINUE will be returned and the method may be re-invoked with the now updated lower and upper range details to proceed. On recoverable error sets *location to be NaN and returns one of suzerain_error_status. On unrecoverable error, additionally calls suzerain_error().

Compute the coefficients \( \gamma_{i} \) for 0 <= i < w->n such that \( \vec{\gamma}\cdot\vec{\beta} = \int_{x_\mbox{lo}}^{x_\mbox{hi}} \sum_{i} \beta_{i} B_{i}^{(\mbox{nderiv})}(x) \, dx\).

Integration bounds outside the support of the basis as well as a reversed bounds are handled correctly. Ranges like [-DBL_MAX,DBL_MAX] are shorthand effectively indicating integration over the support of the B-spline basis.

Parameters
[in]nderivThe derivative to integrate.
[out]coeffsReal-valued coefficients \( \gamma_{i} \).
[in]incStride between elements of coeffs.
[in]loThe lower integration bound \(x_\mbox{lo}\).
[in]hiThe upper integration bound \(x_\mbox{hi}\).
[in]dBTemporary storage to use of size w->k by no less than nderiv + 1.
[in]wWorkspace to use (which sets the integration bounds).
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status.

Compute the "distance" between two B-spline workspaces.

Distance is "huge" if any of the order, number of degrees of freedom, or number of knots differ. When all those criteria match the distance becomes the maximum absolute difference between the knot vectors.

Parameters
aFirst B-spline workspace
bSecond B-spline workspace

Compute the grid spacing scaling factor \(C^{(i)}\) necessary to make \(\left(\frac{\pi}{C\Delta{}x}\right)^i\) a good estimate of the maximum eigenvalue for the \(i\)th Greville abscissae-based, collocation derivative operator when using two-sided hyperbolic tangent stretching.

\(\Delta{}x\) must measure the distance between adjacent collocation points. Beware that spectral-like cases, those where N <= 5*k, will likely give untrustworthy results. See the Suzerain model document for more details.

Parameters
[in]nderivThe desired derivative order. Currently only the values 1 and 2 are acceptable.
[in]kThe B-spline order following GSL conventions. For example, k=4 denotes piecewise cubics.
[in]htdeltaThe nonnegative, two-sided grid stretching parameter.
[in]NThe number of degrees of freedom in the basis.
[out]CThe computed grid spacing scaling factor \(C^{(i)}\).
[out]ClowIf not NULL, a lower error bound on C. That is, a reasonable lower bound on what \(C^{(i)}\) might truly be.
[out]ChighIf not NULL, an upper error bound on C. That is, a reasonable upper bound on what \(C^{(i)}\) might truly be.
See also
suzerain_htstretch2() for more information on the grid stretching.
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status.
