Initialize the logging infrastructure.

Must be called after MPI_Init and before any logging statements.

Parameters

default_conf(Optional) Default configuration to use when neither log4j.configuration nor LOG4CXX_CONFIGURATION is found in the environment. If NULL or zero-length, log4cxx::BasicConfigurator is used.
