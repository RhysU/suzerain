Detailed Description

Encapsulates real-valued filter operator information.

Callers obtain a workspace using suzerain_filterop_alloc() and release it using suzerain_filterop_free().

◆ A_T

double* suzerain_filterop_workspace::A_T

Raw data storage for the unfactored and factored \(A^{\mathrm{T}}\).

The transpose of the operator is stored according to LAPACK GBTRF conventions regarding kl, ku, and n. In particular, this means A + kl is the starting general band storage location for the transpose of the unfactored operator.
