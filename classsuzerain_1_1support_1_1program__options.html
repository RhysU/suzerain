Detailed Description

Performs options parsing for an application, including command line and options file processing.

Includes the following functionality:

  • Allows automatically adding options given an definition_base instance
  • Allows adding options using boost::program_options::options_description_easy_init
  • Provides uniform processing of both command line arguments and files
  • Command line options take precedence over file-based options
  • Earlier file options take precedence over later file options
  • Warns whenever an unrecognized option is provided
  • Provides –help and –version functionality
  • Optionally provides a program description for –help
  • Reads any input files in a scalable way by reading them on the root process and then broadcasting the contents to all ranks.

Process main's argc and argv according to the previously provided options and definition_base instances.

This method performs all necessary parsing, file handling, and notification callbacks. It will throw exceptions on errors. If either –help or –version is encountered the appropriate message will be written on std::cout and exit(0) will be called. Any input files are read by only rank zero of comm and are then broadcast to all other ranks. Error messages are only output by rank zero.

Parameters
argcShould contain main's argc.
argvShould contain main's argv.
commMPI Communicator over which the processing is collective.
debugStream on which debugging messages will be output.
infoStream on which informational messages will be output.
warnStream on which warning messages will be output.
errorStream on which fatal error messages will be output.
Returns
A vector containing all non-option arguments.
