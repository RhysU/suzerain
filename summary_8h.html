Detailed Description

Boost.Preprocessor definitions driving suzerain::summary.

Isolated to ease use, to simplify re-use, and to facilitate debugging.

An all-encompassing sequence like 

* #define SUZERAIN_SUMMARY         \
*     SUZERAIN_SUMMARY_GRID        \
*     SUZERAIN_SUMMARY_SAMPLED     \
*     SUZERAIN_SUMMARY_SAMPLED__Y  \
*     SUZERAIN_SUMMARY_SAMPLED__YY
*

is deliberately not defined. It would contain more than BOOST_PP_LIMIT_SEQ elements and be utterly useless for work with Boost.Preprocessor. However, building blocks called SUZERAIN_SUMMARY_COUNT, SUZERAIN_SUMMARY_FOR_EACH, SUZERAIN_SUMMARY_ENUM_TRANSFORM are provided which circumvents this limit.
