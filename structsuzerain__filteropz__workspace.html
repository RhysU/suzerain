Detailed Description

Encapsulates complex-valued filter operator information.

Callers obtain a workspace using suzerain_filteropz_alloc() and release it using suzerain_filteropz_free(). Many, if not all, of these filters will be real-valued operator stored so that they may be applied to complex-valued data in a single pass through memory.

Given a complex-valued, wave-space field \(x\), compute \( x \leftarrow{} \alpha (F-I) x\).


The implementation accounts for the field potentially being dealiased, distributed across multiple machines, and representing a domain of arbitrary length in the X and Z directions. This routine may also be used to efficiently zero higher wavenumbers used only for dealiasing when dxcnt == 0, dzcnt == 0 (where usually \(\alpha = 1\)). All Nyquist modes are zeroed when dxcnt == 0, dzcnt == 0.

The input and output data x is stored column-major over the Y direction (index range 0 to Ny-1), X direction (index range dkbx to dkex), and Z direction (index range dkbz to dkez). This layout is equivalent to Dmitry Pekurovsky's P3DFFT storage order when Y is specified to be STRIDE1 in wave space. Complex values are stored as C arrays of length two with the real part preceding the imaginary part.

Given two complex-valued, wave-space fields \(x\) and \(y\), compute \( y \leftarrow{} \alpha (F-I) x + \beta{}y\).

The implementation accounts for the field potentially being dealiased, distributed across multiple machines, and representing a domain of arbitrary length in the X and Z directions.

[in]xInput wave-space field to be differentiated
[in]betaComplex-valued scaling factor \(\beta\)
[in,out]yInput and output wave-space field where accumulation takes place.
[in]NyNumber of points in the Y direction
[in]NxNumber of points in the X direction, which determines the maximum wavenumbers which are retained when differentiating.
[in]dNxNumber of dealiased points in the X direction, which determines how offsets are translated into frequencies.
[in]dkbxThe first (inclusive) in-order frequency contained in field x in the X direction.
