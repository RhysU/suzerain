virtual std::size_t suzerain::pencil_grid::local_physical_storage ( ) const
pure virtual

Retrieve the number of contiguous real scalars required to store a pencil's worth of data.

This accounts for any padding required due to differences in the local physical and wave space extents, any padding required by the transformation routines, and the fact that wave storage requires complex scalars.

Returns
Number of real-valued scalars (i.e. suzerain::real_ts) required to store one pencil's contiguous data.

real_t suzerain::pencil_grid::chi ( ) const
inline

The inverse of the product of the global physical extents in X and Z.

This factor shows up repeatedly as a normalization constant. See the model document's "Spatial discretization" section for why and it's "Combined space and time discretization" for how this factor \(\chi\) enters into, e.g., timestepping.

◆ has_zero_zero_modes()

bool suzerain::pencil_grid::has_zero_zero_modes ( ) const
inline

Does this rank possess the "zero-zero" Fourier modes?

More concretely, is local_wave_start.x() == 0 && local_wave_start.z() == 0 && local_wave_extent.prod() > 0 true? The last condition is required to detect degenerate conditions where some ranks may not contain any wave space data.

◆ local_wave_storage()

virtual std::size_t suzerain::pencil_grid::local_wave_storage ( ) const
pure virtual

Retrieve the number of contiguous complex scalars required to store a pencil's worth of data.

This accounts for any padding required due to differences in the local physical and wave space extents, any padding required by the transformation routines, and the fact that physical space storage requires real-valued scalars.

Returns
Number of complex-valued scalars (i.e. suzerain::real_t[2] s) required to store one pencil's contiguous data.

Collectively transform a field from wave space to physical space.

The input will be complex-valued and stored according to local_wave_start() and local_wave_end(). The output will be real-valued and stored according to local_physical_state() and local_physical_end().

◆ processor_grid

Array2i suzerain::pencil_grid::processor_grid

The processor grid extents.

In physical space, \( P_0 \) is the grid extent in the Z direction and \( P_1 \) is the grid extent in the Y direction. In wave space, \( P_0 \) is the grid extent in the X direction and \( P_1 \) is the grid extent in the Z direction.

Returns
the processor grid extents in the \( P_0 \) and \( P_1 \) directions as indices 0 and 1, respectively.
