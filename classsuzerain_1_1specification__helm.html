Detailed Description

Encapsulates PID controller settings and operation using helm.h.

Hides aspects of the incremental control from helm.h to ease use. Const-ness in this class refers to logical const-ness as operating the control mutates internal state. The controller tracks whether or not it has been enabled.

Construct an instance with standard-form control settings.

That is, with coefficients from the equation

\begin{align} \frac{\mathrm{d}}{\mathrm{d}t} v(t) &= k_p \left[ - \frac{\mathrm{d}}{\mathrm{d}t} y(t) + \frac{r(t) - y(t)}{T_i} + \frac{u(t) - v(t)}{T_t} + \frac{T_d}{T_f}\left( \frac{\mathrm{d}}{\mathrm{d}t} f(t) - \frac{\mathrm{d}}{\mathrm{d}t} y(t) \right) \right] . \end{align}

To be enabled, argument kp must be nonzero. After construction, approach must be called once before steady.

Parameters
kpProportional gain modifying P, I, and D terms.


Parameters
TdTime scale governing derivative action.

Set to zero to disable derivative control.

Parameters
TfTime scale filtering process observable for D.

Set to infinity to disable observable filtering.

Set to infinity to disable integral control.

Set to infinity to disable automatic reset.
