Perform Richardson extrapolation on \(A_{i}(h)\) and \(A_{i}(h/t)\) to get \(A_{i+1}(h)\).

Given \(A_{i}(h)\), an approximation of \(A\) such that \(A - A(h) = a_{i} h^k_{i} + a_{i+1} h^k_{i+1} + \dots\) use Richardson extrapolation to find an approximation to leading order \(k_{i+1}\) from evaluations at \(A_{i}(h)\) and \(A_{i}(h/t)\) for \(t > 0\). Specifically, \(A_{i+1}(h) = (t^{k_{i}} A_{i}(h/t) - A_{i}(h)) / (t^{k_{i}} - 1)\).

Parameters
[in,out]AhOn entry, the coarser approximation \(A_{i}(h)\). On exit, the extrapolated approximation \(A_{i+1}(h)\).
[in]AhtThe finer approximation \(A_{i}(h/t)\)
[in]kiThe leading term order in the Taylor expansion \(k_{i}\)
[in]tThe refinement factor between the two approximations
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status. The parameter Ah will be in an undefined state after any error.

Perform Richardson extrapolation on a sequence of refined approximations.

The routine can perform multiple step extrapolation, e.g. using \( A_{0}(h) \), \( A_{0}(h/2) \), and \( A_{0}(h/4) \) to compute \( A_{2}(h) \).

See also
suzerain_richardson_extrapolation_step() for details on each extrapolation step and the terminology used.
Parameters
[in,out]AOn entry, column i of A contains \( A_{0}(h/t^{i})\). On exit, column 0 of A contains \( A_{A->size2}(h) \). Other columns will be overwritten.
[in]tThe refinement factor between the two approximations.
[in]kLeading error term orders. Assumed to start at 1 if NULL provided. Assumed to increment by 1 if no second element provided. If the vector is shorter than A->size2, any unspecified higher index entries are assumed to grow by k(k->size-1) - k(k->size-2).
[out]normtableIf non-NULL, the routine outputs a table showing the \( \ell_2 \) error at each step in the extrapolation process calculated against the provided exact parameter.
[in]exactExact solution used to calculate normtable. If NULL, exact is treated as if it contained all zeros.
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status. The parameters A and normtable will be in an undefined state after any error.
