Compute an approximation to the maximum stable time step according to the convective criterion for the three dimensional Euler equations.

This surrogate is a model for the convective portion of the Navier-Stokes operator. This criterion appears as equation 2.39 in Wai Y. Kwok's thesis (2002) and equations 4.20 and 4.21 in Stephen Guarini's thesis (1998):

\[ \Delta{}t \leq \frac{ \left|\lambda_{I}\Delta{}t\right|_{\max} }{ \left(\left|u_{x}\right| + a\right) \lambda^{(1)}_x + \left(\left|u_{y}\right| + a\right) \lambda^{(1)}_y + \left(\left|u_{z}\right| + a\right) \lambda^{(1)}_z } \]

where \(a\) is the local acoustic velocity, \(u_{x}\) denotes the velocity in the X direction, \(\lambda^{(1)}_x\) represents the maximum imaginary eigenvalue magnitude of the first derivative operator in the $x$ direction, etc. The maximum pure imaginary eigenvalue magnitude, \(\left|\lambda_{I}\Delta{}t\right|_{\mbox{max}}\), is a feature of the chosen timestepping method. For example, it is \(\sqrt{3}\) for the smr91 scheme. See the Suzerain model document for details on estimating \(\lambda^{(1)}_x\), \(\lambda^{(1)}_y\), and \(\lambda^{(1)}_z\).

For formulations in which an explicit Mach number \(\mbox{Ma}=\frac{u_0}{a_0}\) appears, one must provide the velocities and the sound speed both nondimensionalized using \(u_0\). That expressions like \(\left|u\right| + \frac{a}{\mbox{Ma}}\) are appropriate in that context can be seen by finding the eigenvalues of the Euler equations in such a nondimensionalization.

Using a hybrid implicit/explicit timestepper with acoustic terms computed implicitly effectively sets the sound speed to be zero for this CFL calculation. Three different acoustic velocities \(a_x\), \(a_y\) and \(a_z\) may be specified to accommodate when only some directions have implicitly treated acoustics.

Compute an approximation to the maximum stable time step according to the viscous stability criterion for a three-dimensional model diffusion equation.

This surrogate is a model for the diffusive part of the Navier-Stokes operator. This criterion appears as equation 2.40 in Wai Y. Kwok's thesis (2002) and equations 4.29 and 4.30 in Stephen Guarini's thesis (1998):

\[ \Delta{}t \leq \frac{ \left|\lambda_{R}\Delta_{}t\right|_{\max} }{ \max\left( \left|\frac{\gamma\left(\nu-\nu_{0}\right)}{\mbox{Re}\mbox{Pr}}\right|, \left|\frac{\nu-\nu_{0}}{\mbox{Re}}\right|, \left|\frac{\nu_{B}-\nu_{B0}}{\mbox{Re}}\right| \right) \left( \lambda^{(2)}_x + \lambda^{(2)}_y + \lambda^{(2)}_z \right) } \]

where a bulk kinematic viscosity \(\nu_{B}\) has been added. See the Suzerain model document for details on estimating \(\lambda^{(2)}_x\), \(\lambda^{(2)}_y\), and \(\lambda^{(2)}_z\). The maximum pure real eigenvalue magnitude, \(\left|\lambda_{R}\Delta{}t\right|_{\mbox{max}}\), is a feature of the chosen timestepping method. For example, it is 2.512 for the smr91 scheme. The absolute values within the maximum operation account for the possibility that \(\nu<\nu_{0}\).

Using a hybrid implicit/explicit timestepper with viscous terms computed implicitly sets \(\nu_0\) to be the reference kinematic viscosity about which the viscous terms were linearized.

PrThe Prandtl number \(\mbox{Pr}\)
gammaThe ratio of specific heats \(\gamma\)
evmaxmag_realThe maximum pure real eigenvalue magnitude for some Runge-Kutta scheme, denoted \(\left| \lambda_{R}\Delta_{}t \right|_{\mbox{max}}\) in Guarini's thesis.
nuThe local kinematic viscosity \(\nu\)
nu0The kinematic viscosity reference value \(\nu_{0}\)
nuBThe local bulk kinematic viscosity \(\nu\)

Using the given method and a linear and nonlinear operator, take substep substep_index while advancing from \(u(t)\) to \(u(t+\Delta{}t)\) using a hybrid implicit/explicit scheme to advance the system \( M u_t = Lu + \chi N(u,t) \).

Notice the presence of scaling factor \(\chi\) within the substep equation. Because the roles of state locations a and b are swapped after each substep, and in contrast to step(), only a single state type may be supplied to this method.

Parameters
mThe low storage scheme to use. For example, method in conjunction with smr91.
LThe linear operator to be treated implicitly.
chiThe factor \(\chi\) scaling the nonlinear operator.
NThe nonlinear operator to be treated explicitly.
timeThe simulation time \(t\) at which the substep occurs.
aOn entry contains \(u^{i}\) and on exit contains \(N\left(u^{i}\right)\).
bOn entry contains \(N\left(u^{i-1}\right)\) and on exit contains \(u^{i+1}\).
substep_indexThe substep number to take.
delta_tThe time step \(\Delta{}t\) to take. The same time step should be supplied for all substep computations throughout a given step.
Returns
The time step \(\Delta{}t\) taken. It will always equal delta_t.
See also
method_interface for the equation governing time advancement.

Using the given method and a linear and nonlinear operator, take substep substep_index while advancing from \(u(t)\) to \(u(t+\Delta{}t)\) using a hybrid implicit/explicit scheme using the system \( M u_t = Lu + \chi N(u,t)\).

Notice the presence of scaling factor \(\chi\) within the substep equation. The time step taken, \(\Delta{}t\), will be based on a stable value computed during the first nonlinear operator application as well as an optional fixed maximum step size.
