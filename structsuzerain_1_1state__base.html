Detailed Description

template<class Derived>
class suzerain::state_base< Derived >

Base class for all of Suzerain's state implementations.

Static polymorphism via the Curiously Recurring Template Pattern is used to look up the appropriate type-specific functionality. Subclasses are usable with functionality found in lowstorage.
