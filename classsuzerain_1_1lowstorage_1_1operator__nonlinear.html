Apply the operator in place on a given state location.

That is, compute \(\mbox{state}\leftarrow{}\mbox{operator}\left(\mbox{state}\right)\).

Parameters
timeThe time at which to apply the operator.
stateThe state location to use. It is expected that certain implementations will require more specific state types.
methodThe low storage scheme being used. When substep_index == 0 the operator should use this information to compute a stable time step.
substep_indexThe (zero-indexed) current time step substep. If zero the operator should compute and return stable time steps according to one or more criteria.
Returns
stable time step sizes according to one or more criteria if substep_index == 0. The overall stable time step is the minimum of all elements in the returned vector. Returning results from multiple criteria allows monitoring the relative restrictness of each criterion.
