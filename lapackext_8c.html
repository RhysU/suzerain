Detailed Description

LAPACK-like extensions built atop LAPACK, the BLAS, and/or on custom coded loops. Some of these extensions resemble newer LAPACK features which have not trickled down to banded matrices from general matrices.

Compute the solution to a banded system of linear equations \( AX=B \) using an in-place LU factorization. This is implemented as a possible call to GBTRF followed by a call to GBTRS.

Transposes of \( A \) can be taken using the trans parameter.

Parameters
[in,out]factOne of 'N' or 'F'. When 'N' on entry, \( A \) is factorized and fact is set to 'F' on exit. Otherwise, \( A \) must have been factorized in-place by a previous call to this method employing 'N'.
[in]transOne of 'N', 'T', or 'C' for no transpose, a transpose, or a conjugate transpose, respectively.
[in]n
[in]kl
[in]ku
[in]nrhs
[in,out]abDimension (ldab,n)
[in]ldabMinimum kl + ku + 1
[in,out]ipivDimension n
[in,out]bDimension (ldb,nrhs)
[in]ldbMinimum n
Returns
Zero on successful execution. Nonzero otherwise.
