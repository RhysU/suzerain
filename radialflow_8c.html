Detailed Description

A GNU Scientific Library-based axisymmetric radial flow solver.

Solves isenthalpic flows in nondimensional primitive variables. Use suzerain_radialflow_solver to produce a suzerain_radialflow_solution.

suzerain_radialflow_solution * suzerain_radialflow_solver ( const double  Ma0,
const double  gamma,
const double  u1,
const double  rho1,
const double  p1,
const double *const  R,
const size_t  size 
)

Solve the requested radial nozzle problem.

That is, advance the system

\begin{align} u^\prime &= \frac{u}{r} \, \frac{ \left[ 2 \mbox{Ma}_0^{-2} + \left(\gamma-1\right) \left(1 - u^2\right) \right] }{ 2 u^2 - \left[ 2 \mbox{Ma}0^{-2} + \left(\gamma-1\right) \left(1 - u^2\right) \right] } \\ \rho^\prime &= \frac{1}{a^2} p^\prime \\ p^\prime &= -\frac{\mbox{Ma}_0^2}{2} \rho u u^\prime \end{align}

employing the equation of state

\begin{align} a^2 &= 1 + \mbox{Ma}_{0}^2\frac{\gamma-1}{2}\left(1-u^2\right) \end{align}

to solve for the quantities in suzerain_radialflow_state as a function of \(R\) given initial conditions \(\rho\left(r_1\right)\) and \(u\left(r_1\right)\) satisfying the realizability constraint

\begin{align} u^2 &< \frac{2}{\mbox{Ma}_{0}^2\left(\gamma-1\right)} + 1 . \end{align}

Parameters
Ma0Reference Mach number \(\mbox{Ma}_0\).
gammaReference specific heat ratio \(\gamma \).
u1Initial radial velocity \(u \left(R_1\right)\).
rho1Initial density \(\rho\left(R_1\right)\).
p1Initial pressure \(p \left(R_1\right)\).
RRadii of interest with \(R_1\) taken from R[0]. Must be a contiguous array of length size with either increasing or decreasing values.
sizeNumber of radii within R.
Returns
On success returns a suzerain_radialflow_solution encapsulating the solution details. The caller is responsible for subsequently freeing the returned pointer. On failure calls suzerain_error() and returns NULL.

Takes locations s->state[j].R to be along a positive- \(y\)-oriented line segment beginning at Cartesian position \(\left(R_0,0\right)\) and extending until \(\left(R_0,\delta\right)\) where \(\delta=\sqrt{R_i^2 - R_0^2}\) and \(R_0\) is taken from the minimum s->state[j].R.

Compute \(\mbox{Ma}_e\), the edge Mach number, at location index i within solution s.

That is,

\begin{align} \mbox{Ma}_{e} &\equiv \left. \frac{u_0 u_\xi}{a_0 a} \right|_{\left(R_0,\delta\right)} = \left. \frac{\mbox{Ma}_{0} R_0}{R} \frac{\left|u\left(R\right)\right|} { a\left(R\right) } \right|_{R = \sqrt{R_0^2 + \delta^2}} \end{align}

where \(\xi\) is denotes the \(x\) direction possibly reflected so that streamwise velocity always has positive sign. \(\delta\) is computed from suzerain_radialflow_delta using s and i. Given these geometric assumptions, only the \(\xi\)-component of the radial velocity \(u\left(R\right)\) contributes to \(\mbox{Ma}_e\).

Parameters
sA solution generated by suzerain_radialflow_solver.
iAn indexed location within s in range [0,s->size).
Returns
\(\mbox{Ma}_e\) computed using described geometric assumptions.

Compute \(p^\ast_{e,\xi}\), a nondimensional pressure gradient parameter, at location index i within solution s.

That is,

\begin{align} p^\ast_{e,\xi} &\equiv \left. \frac{l_0 \delta}{\rho_0 \rho \, u_0^2 u^2} \frac{\partial\left(p_0 p\right)}{\partial\left(l_0 \xi\right)} \right|_{\left(R_0,\delta\right)} \\&= \left. \frac{\operatorname{sgn}(u) \, \delta}{\mbox{Ma}_{0}^2 \rho u^2} \frac{\partial{}p}{\partial{}x} \right|_{\left(R_0,\delta\right)} \\&= \left. \frac{\operatorname{sgn}(u) R \, \delta \, p^\prime\left(R\right)} {\mbox{Ma}_{0}^2 R_0 \, \rho\left(R\right) u^2\left(R\right)} \right|_{R=\sqrt{R_0^2 + \delta^2}} \\&= - \left. \frac{R \, \delta \, u'\left(R\right)} {R_0 \, \left|u\left(R\right)\right|} \right|_{R=\sqrt{R_0^2 + \delta^2}} \end{align}

where \(\xi\) is denotes the \(x\) direction possibly reflected so that streamwise velocity always has positive sign. \(\delta\) is computed from suzerain_radialflow_delta using s and i. Given these geometric assumptions, only the \(\xi\)-component of the pressure gradient \(p^\prime\left(R\right)\) contributes to \(p^\ast_{e\,\xi}\).

iAn indexed location within s in range [0,s->size).

\(p^\ast_{e,\xi}\) computed using described geometric assumptions.

Compute \(\mbox{T}_e\), the edge temperature under ideal gas assumptions, at location index i within solution s.

That is,

\begin{align} \mbox{T}_{e} &\equiv \gamma \frac{p \left(x,y;\mbox{Ma}\right)} {rho\left(x,y \right)} = \left. \gamma \frac{\mbox{Ma}^2 p \left(R\right)} {\mbox{Ma}^2_0 rho\left(R\right)} \right|_{R = \sqrt{R_0^2 + \delta^2}} . \end{align}

Here, \(\mbox{Ma}\) is the Mach number for some target nondimensionalization sharing references \(u_0\), \(\rho_0\), and relationship \(p_0=\rho_0 a_0^2\) but not necessarily \(a_0\).

Compute Cartesian base flow primitive state at \(\left(R_0, \delta_i\right)\), including streamwise derivatives, given a radial nozzle solution.

Downstream \(\xi\) is oriented to be in the positive \(x\) direction regardless of the sub- versus supersonic nature of the radial solution. Coordinate \(\delta\) is computed from suzerain_radialflow_delta using s and i. Parameter \(\mbox{Ma}\) permits translating the nondimensional results into a setting where \(\mbox{Ma} \ne \mbox{Ma}_0\).
