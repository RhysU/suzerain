Detailed Description

Defines typedefs for Eigen-related classes within the suzerain namespace.

Typedefs like Matrix3r and Vector3c permit simplifying using suzerain::real_t and suzerain::complex_t with Eigen's Matrix and Array templates. They also permit codifying Suzerain's expectations regarding column- versus row-major storage regardless of the value of EIGEN_DEFAULT_TO_ROW_MAJOR.
