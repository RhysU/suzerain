Detailed Description

template<typename ValueType, std::size_t NumDims>
class suzerain::multi_array::ref< ValueType, NumDims >

A boost::multi_array_ref-like class for strided indexing into a contiguous region of memory provided to the constructor.

Nearly all of the implementation is inherited, but we choose to avoid publicly being a multi_array_ref subclass since the underlying elements are not strictly contiguous.

See also
Boost.MultiArray for more information on the MultiArray concept.
