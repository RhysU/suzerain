Accumulate the `‘zero-zero’' mode linear implicit operator application \(y \leftarrow{} \left(M + \varphi{}L\right) x + \beta{} y\).

This method is equivalent to calling suzerain_rholut_imexop_accumulate() using km == 0 and kn == 0 but should be appreciably faster.
