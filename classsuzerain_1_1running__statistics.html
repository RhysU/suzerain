Detailed Description

template<typename Real, std::size_t N>
class suzerain::running_statistics< Real, N >

Accumulates running minimum, maximum, mean, and variance details from a data stream.

Adapted from http://www.johndcook.com/standard_deviation.html. Extended to track a fixed number of distinct quantities with concurrently provided samples and to permit merging statistics from multiple instances. Storage overhead reduced relative to Cook's presentation.

Template Parameters
RealFloating point type used for input and accumulation
NNumber of distinct quantities to simultaneously track
