Detailed Description

Provides function templates for BLAS level 1, 2, and 3 functionality.

Also includes functionality from the BLAS Technical Forum Standard.

void * suzerain::blas::malloc ( size_t  size)
inline

Allocates memory aligned according to SUZERAIN_BLAS_ALIGNMENT.

The memory is not cleared. Any returned memory must later be freed using suzerain_blas_free().

Parameters
sizeNumber of bytes to allocate.
Returns
On success, return a pointer to the allocated memory. On failure, return a NULL pointer.
