Detailed Description

Provides routines for performing FFTs along a "pencil", one direction of a potentially multidimensional array.

In particular, provides such routines atop the Boost.MultiArray concept.

See also
Boost.MultiArray for more information on the MultiArray concept.

Perform a forward complex-to-complex FFT on each 1D "pencil" of in storing the result in out.

Data is transformed from physical space to wave space. If desired, the data can be differentiated. For the transform to proceed without any dealiasing, it must be true that in.shape()[transform_dim] == out.shape()[transform_dim].

Parameters
transform_dimzero-indexed dimension indicating the pencils to be transformed.
inan instance modeling the MultiArray concept containing the complex-valued physical space input data to transform.
outan instance modeling the MultiArray concept to contain the complex-valued wave space output data from the transform.
domain_lengthUsed when differentiating the data during the transformation.
derivativeIf nonzero, the data is differentiated during the transform process.
fftw_flagsFFTW planner flags to use when computing the transform. For example, FFTW_MEASURE or FFTW_PATIENT.
See also
internal::c2c_transform for more details on the transform process.

Perform a forward real-to-complex FFT on each 1D "pencil" of in storing the result in out.

Data is transformed from physical space to wave space. If desired, the data can be differentiated. For the transform to proceed without any dealiasing, it must be true that in.shape()[transform_dim] == out.shape()[transform_dim]/2 + 1.

Parameters
transform_dimzero-indexed dimension indicating the pencils to be transformed.
inan instance modeling the MultiArray concept containing the real-valued physical space input data to transform.
outan instance modeling the MultiArray concept to contain the complex-valued wave space output data from the transform. Only the nonnegative wavenumber indices are stored because the forward transform of real-valued data has conjugate symmetry.
domain_lengthUsed when differentiating the data during the transformation.
derivativeIf nonzero, the data is differentiated during the transform process.
fftw_flagsFFTW planner flags to use when computing the transform. For example, FFTW_MEASURE or FFTW_PATIENT.
