Detailed Description

Builds a hybrid implicit/explicit-ready lowstorage::operator_nonlinear from an implicit-agnostic lowstorage::operator_nonlinear and a compatible lowstorage::linear_operator.

More concretely, suppose one wants to use the hybrid implicit/explicit timestepping schemes defined in lowstorage which the state vector \( u(t) \) is advanced to \(u(t+\Delta{}t)\) according to

\[ M u_{t} = Lu + \chi N(u) \]

where \(M\), \(L\), and \(N\) are linear, linear, and nonlinear operators, respectively. Scalar \(\chi\) is a fixed multiplicative factor often used to hide FFT normalization costs. Instead of \(N\) you have a fully explicit operator implementation $R$ per

\[ M u_{t} = \chi R(u). \]

and an implementation of \(M + \phi L\) per lowstorage::linear_operator. To use the low-storage implicit-explicit interface you need

\[ N(u) = R(u) - \frac{1}{\chi} Lu. \]

.

This class programmatically implements such an \(N\) given implementations of \(R\) and \(M + \phi L\). It permits having your \(N\) automatically adjust to any sane \(L\) implementation but it comes at the cost of nontrivial additional memory and moderate runtime overhead.

When a good \(L\) and \(R\) combination is found, it is well worthwhile to encode the corresponding \(N\) directly rather than to continue using this adaptor.

Apply the operator in place on a given state location.

That is, compute \(\mbox{state}\leftarrow{}\mbox{operator}\left(\mbox{state}\right)\).

Parameters
timeThe time at which to apply the operator.
stateThe state location to use. It is expected that certain implementations will require more specific state types.
methodThe low storage scheme being used. When substep_index == 0 the operator should use this information to compute a stable time step.
substep_indexThe (zero-indexed) current time step substep. If zero the operator should compute and return stable time steps according to one or more criteria.
Returns
stable time step sizes according to one or more criteria if substep_index == 0. The overall stable time step is the minimum of all elements in the returned vector. Returning results from multiple criteria allows monitoring the relative restrictness of each criterion.
