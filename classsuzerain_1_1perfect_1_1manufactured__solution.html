Detailed Description

Manufactured solution employed throughout the perfect gas code.

By subclassing support::definition_base we can pass an instance to program_options::add_definition method to permit modifying parameters via the command line.

None of alpha, beta, gamma, Ma, Pr, Re or Lx, Ly, Lz are modified when used in this fashion. The former group will need to be synced using match(const definition_scenario&) and the later group using match(const specification_grid&).

A single method for simultaneously computing forcing for all five equations in a conservative formulation at a given location.

That is, computing Q_rho(), Q_rhou(), Q_rhov(), Q_rhow(), and Q_rhoe(). Faster than using those five methods separately because it eliminates redundant computations.

Parameters
[in]xX coordinate at which to evaluate forcing
[in]yY coordinate at which to evaluate forcing
[in]zZ coordinate at which to evaluate forcing
[in]tTime coordinate at which to evaluate forcing
