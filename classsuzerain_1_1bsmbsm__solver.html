Detailed Description

An abstract base class for solving BSMBSM problems per a specification_zgbsv.

To use the interface, users

  1. obtain a subclass instance,
  2. invoke supply_B or supply_b to set the right hand side(s),
  3. supply an unfactored operator into PAPT per suzerain_bsmbsm.h,
  4. invoke supplied_PAPT,
  5. invoke solve to factorize and perform backsubstitution,
  6. and finally invoke demand_X or demand_x to obtain the solution.

If spec.in_place() == true, storage LU and PAPT are coincident as are PB and PX. For maximum flexibility, it should be assumed that calling solve destroys the contents of PB and PAPT.

Users can, and should, reuse an instance for repeatedly solving problems of some given size. Factorizations will be reused when possible. When a new operator is of interest, invoke supplied_PAPT again to inform the instance that a new operator is stored in PAPT. If spec.reuse(), subclasses may attempt to reuse the previous factorization unless apprx(const bool) is called after supplied_PAPT. For example, supplied_PAPT.apprx(false).

See also
The definition of a BSMBSM problem in bsmbsm.h.
