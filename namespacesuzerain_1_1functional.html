Compute the product of the values in the range [first,last) with init.

This combines std::accumulate with std::multiplies<T>. Note that init controls the multiplication rules in use.

Parameters
firstInitial position in a sequence.
lastFinal position in a sequence.
initInitial value for the product.
Returns
The result of taking the product of init with all values in the range [first,last).
