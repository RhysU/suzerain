Scenario information from fully-laminar CEV simulations at International Space Station return peak heating conditions.

Simulations by Paul Bauman using the FIN-S hypersonic flow code. Postprocessing performed by Rhys Ulerich per https://svn.ices.utexas.edu/repos/pecos/turbulence/heatshield_bl/. Reduced data is tracked within notebooks/cev_iss_lam.in. It has been reordered relative to that data file to permit interpolation.

Parameters
dstagLeeward distance from the stagnation point in meters.
gammaeRatio of specific heats at the boundary layer edge.
gammawRatio of specific heats at the wall.
MaeMach number at the boundary layer edge.
PrePrandtl number at the boundary layer edge.
PrwPrandtl number at the wall.
pexiThe inviscid-friendly pressure parameter \(p_{e,x}^\ast = \frac{\delta}{\rho_e u_e^2} \frac{\partial p}{\partial x}\).
T_ratioThe edge-to-wall temperature ratio, \(T_e / T_w\).
Returns
SUZERAIN_SUCCESS on success. On error throws an exception.
