Detailed Description

Encapsulates basis function and derivative operator information.

Callers obtain a workspace using suzerain_bsplineop_alloc() and release it using suzerain_bsplineop_free().

Apply the nderiv-th derivative operator to real coefficients x.

Multiplies the precomputed banded derivative operator scaled by alpha against one or more coefficient vectors stored in x. Results overwrite x. Each coefficient vector is of length w->n.

Parameters
[in]nderivDerivative operator to apply. May be zero.
[in]nrhsNumber of coefficient vectors stored in x.
[in]alphaReal scaling factor to apply.
[in,out]xCoefficients to be multiplied.
[in]incxStride between elements stored in x.
[in]ldxLeading dimension of the data stored in x.
[in]wWorkspace to use.
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status.

Apply the nderiv-th derivative operator to real coefficients x accumulating the results in y.

Multiplies alpha times the precomputed banded derivative operator against one or more coefficient vectors stored in x. Results are added to beta times y. Each coefficient vector is of length w->n. x and y cannot be aliased.

[in]alphaMultiplicative factor to use on x.

[in]betaMultiplicative factor to use on y.

Determine the right hand side of the interpolation problem D[0] x = rhs.

Here D[0] is the zeroth derivative operator (i.e. mass matrix), x are the basis function coefficients that will best represent function for the given method, and rhs is the vector computed by this routine.

Parameters
[in]functionReal-valued function to use when computing rhs.
[out]rhsOutput vector containing computed right hand side
[in]bwWorkspace to use which must have been the one used to create w.
[in]wWorkspace to use.
Returns
SUZERAIN_SUCCESS on success. On error calls suzerain_error() and returns one of suzerain_error_status.
See also
suzerain_bsplineop_method() for details on available methods. Different methods will necessarily compute the right hand side differently.
suzerain_bsplineop_lu_opaccumulate(), suzerain_bsplineop_lu_factor(), and suzerain_bsplineop_lu_solve() for how to solve the linear equation for x.
suzerain_bsplineop_interpolation_rhs_complex() for a way to perform this operation for a complex-valued function.

◆ D_T

double** suzerain_bsplineop_workspace::D_T

Storage for each banded derivative operator matrix.

This general band storage can be accessed in two different ways:

  • D_T[k] is the band storage for the transpose of the k-th derivative using kl[k], ku[k], and ld. This view is optimal for BLAS gbmv operations using TRANS == 'T'.
  • D_T[k] - (max_ku - ku[k]) is the same band storage for the transpose of the k-th derivative viewed using max_kl, max_ku, and ld. This view is optimal for BLAS gb_acc and gb_add operations.
