Detailed Description

template<typename T>
class suzerain::allocator_freestore_policy< T >

A free-store based allocation policy.

Uses global operator new and global operator delete to handle allocate and deallocate invocations.

See also
Lai Shiaw San Kent's article C++ Standard Allocator, An Introduction and Implementation for more information.
