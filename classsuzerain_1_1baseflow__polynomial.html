◆ x

MatrixXXr suzerain::baseflow_polynomial::x

Polynomial coefficients for the fields.

Each variable in the baseflow is represented by one column in x. Each column encodes one polynomial in the format the GSL Polynomial Evaluation routines expect. Derivatives in the \(y\) direction are taken from the same coefficient representation. Pressure information is stored in the final column. This member must have the same number of columns as dx but the number of rows may differ.

◆ dx

MatrixXXr suzerain::baseflow_polynomial::dx

Polynomial coefficients for the field \(x\) derivatives.

These are stored analogously to x. In particular, this member must have the same number of columns as x but the number of rows may differ.
