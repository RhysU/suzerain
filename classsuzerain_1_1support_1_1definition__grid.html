Detailed Description

Upgrades a specification_grid with definition_base behavior.

This permits using the instance with program_options.

The hyperbolic tangent stretching parameter to use when computing breakpoint locations.

Positive values indicate two-sided stretching. Negative values indicate one-sided stretching.

suzerain_htstretch1() and suzerain_htstretch2() for examples of how this parameter is used.
