Detailed Description

template<class Target, class Source, class Enable = void>
struct suzerain::functional::assign< Target, Source, Enable >

A functor that performs assignment to type Target from type Source.

Target must be assignable from Source.

The Enable template parameter allows using boost::enable_if to specialize or partially specialize the functor per enable_if's documentation section 3.1: Enabling template class specializations.
