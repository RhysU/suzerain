Create a POSIX pipe, set the provided flags on the read and write portions, and create a FILE* handle to the write end suitable for use with fprintf and friends.

Parameters
[out]rfdFile descriptor attached to the pipe's read side.
[in]rflagsFlags to set for the new pipe's read side.
[out]wHandle return for the new pipe's write side.
[in]wflagsFlags to set for the new pipe's write side.
See also
The manual pages for fcntl(2), pipe(2), and pipe(7) for more information on creating pipes and the effect of their flags.
The manual pages for close(2) and fclose(3) for information on how to close rfd and *write after you have finished using them.
Returns
Zero on successful completion. On non-zero returns SUZERAIN_FAILURE and errno is set appropriately.

◆ suzerain_temporary_directory()

const char * suzerain_temporary_directory ( )

Obtain a "good" temporary directory name which is likely to be on non-networked disk.

Uses the first of the following environment variables found which, after leading spaces are removed, has non-zero length:

  • TMPDIR
  • TMP
  • TEMPDIR
  • TEMP If none of these possibilities give a non-empty result, the method returns the string "/tmp".
Returns
The name of a temporary directory.
