Detailed Description

template<typename Element>
class suzerain::lowstorage::method_interface< Element >

Encapsulates a hybrid implicit/explicit low storage Runge-Kutta method to advance \(u(t)\) to \(u(t+\Delta{}t)\).

The method consists of one or more substeps governed by coefficients \(\alpha_i\), \(\beta_i\), \(\gamma_i\), \(\zeta_i\), and \(\eta_i\) where \(i\) is less than the number of substeps. Each substep obeys

\[ \left(M - \Delta{}t\beta_{i}L\right) u^{i+1} = \left(M + \Delta{}t\alpha_{i}L\right) u^{i} + \Delta{}t\gamma_{i} N\left(u^{i},t + \eta_{i}\Delta{}t\right) + \Delta{}t\zeta_{i} N\left(u^{i-1}, t + \eta_{i}\Delta{}t\right) \]

where \(\alpha_i+\beta_i=\gamma_i+\zeta_i\) and \(\eta_{i} = \sum_{i=0}^{i-1} \alpha_{i} + \beta{i} \). Note that the indexing on the \(\zeta_i\) coefficients differs slightly from other sources. Note also that not all literature sources include the possibility of a time-dependent \(N\) operator.

The ith substep has a "duration" \(d_i = \left(\eta_{i+1} - \eta_i\right)\Delta{}t\) where \(i+1\) greater than the number of substeps is treated as 1. A running mean quantity across \(N\) substeps, denoted \(\bar{q}_{N-1}\), may be accumulated via

\[ \bar{q}_{N-1} = \frac{\sum_{i=0}^{N-1} d_{i} q_{i}} {\sum_{i=0}^{N-1} d_{i} }. \]

Rearranging the result in terms of means from earlier substeps,

\[ \bar{q}_{N-1} = \frac{\sum_{i=0}^{N-2}} {d_{N-1} + \sum_{i=0}^{N-2} d_i} \bar{q}_{N-2} + \frac{d_{N-1}} {d_{N-1} + \sum_{i=0}^{N-2} d_i} q_{N-1} \]

motivates defining

\[ \iota_{N-1} = \frac{d_i}{\sum_{i=0}^{N-1} d_i} = \frac{\eta_{i+1} - \eta_i}{\eta_{i+1} - \eta_{0}} = \frac{\eta_{i+1} - \eta_i}{\eta_{i+1}} \]

since the factor \(\Delta{}t\) may be omitted without changing \(\bar{q}_{N-1}\) and \(\eta_{0} = 0\). Then maintaining the running mean

\[ \bar{q}_{N-1} = \left(1 - \iota_{N-1}\right) \bar{q}_{N-2} + \iota_{N-1} q_{N-1} \]

may be done via a simple update operation mean += iota_i * (sample - mean). One use case for \(\iota_i\) is obtaining running means of quantities varying at each substep using minimal space and time overhead.

Similarly to \(\iota_i\), for quantities in effect only during linear operator application, \(\Delta{}t \alpha_i L\), one can define

\[ \iota_{\alpha,N-1} = \frac{\alpha_i}{\eta_{i+1}}. \]

Analogously,

\[ \iota_{\beta,N-1} = \frac{\beta_i}{\eta_{i+1}} \]

for is defined for quantities in effect only during linear operator "inversion", \(\left(M - \Delta{}t \beta_i L\right)^{-1}\). The former is useful for obtaining averages implicitly-computed forcing terms which are applied for duration \(\alpha_i \Delta{}t\) but computed during the operator inversion stage. In both cases, running weighted means are computed in-place as mean += iota_alpha_i * (sample - mean) or mean += iota_beta_i * (sample - mean).
