rigor suzerain::fftw::rigor_from ( const char *  name)

Convert from a human-readable name into a rigor flag.

Comparisons are case insensitive and at most only the first two characters are examined. This causes, for example, 'p', 'P', 'patIENT', and 'pAtRiArch' to all be treated as patient. Ambiguous values are treated towards less costly planning, e.g. 'e' is treated as estimate and not exhaustive. Unknown strings are converted to measure.

int suzerain::fftw::default_nthreads ( )

Retrieve a sensible default number of threads for threaded FFTW planning.

Takes into account whether or not threading is available and the desired threading method. For example, it uses OMP_NUM_THREADS when OpenMP threading is used.
