Detailed Description

Logic for working with B-spline operators.

Provides B-spline-based banded operator construction and application routines.

Both real- and complex- valued operator application and inversion are supported. The derivative operators map a function's spline coefficients to an approximation of the derivative's spline coefficients.

For collocation-based operators, the approximation \(\tilde{\gamma}(x) = \sum_{i} \beta_{i} B_{i}(x)\) to the continuous operator \(\mathcal{D}\) acting on \(\tilde{\phi}(x) = \sum_{i} \alpha_{i} B_{i}(x)\) must satisfy \(\tilde{\gamma}(x_j) = \left(\mathcal{D}\tilde{\phi}\right)(x_j)\) at each collocation point \(x_j\). This implies

\[ \sum_{i} \beta_{i} B_{i}(x_j) = \sum_{i} \alpha_{i} \mathcal{D}(B_i)(x_j) \quad \forall{} j. \]

The \(k\)-th collocation derivative operator matrix is given by \(D^k_{i,j}=\left(B^{(k)}_j(x_i)\right)\). Conveniently, the matrix-vector product of a collocation derivative matrix with a B-spline coefficient vector is equivalent to evaluating the linear combination of the basis functions at the collocation points.

For Galerkin-based operators, the relationship \( \left( B_j, \tilde{\gamma}\right) = \left(B_j, \mathcal{D}\tilde{\phi}\right)\) must hold for each spline basis index \(j\) where \((f,g)\) denotes the \(L_2\) inner product. This implies

\[ \sum_{i} \beta_{i} \left( B_j, B_i \right) = \sum_{i} \alpha_{j} \left( B_j, \mathcal{D}B_i \right). \]

The \(k\)-th Galerkin derivative operator matrix is given by \(D^k_{i,j}=\left(B_j,B^{(k)}_i\right)\). For either method, applying the \(k\)-th derivative operator requires solving the linear problem \(D^{0} \beta = D^{k} \alpha\). The method to use is chosen through the suzerain_bsplineop_method value provided to suzerain_bsplineop_alloc().

All operator matrices are stored transposed in column-major (Fortran) storage. The operator transposes are stored so that discrete operator application (which is nothing but a matrix-vector product) has an optimal memory access pattern. Multiple threads may call the routines simultaneously provided that each thread has its own workspace instances. The behavior is undefined if two threads simultaneously share a workspace. Internally, the code builds upon the GNU Scientific Library (GSL) B-spline routines and uses banded matrix BLAS and LAPACK functionality where possible.

See also
A Critical Evaluation of the Resolution Properties of B-Spline and Compact Finite Difference Methods by Kwok, Moser, and Jimenez published in the Journal of Computational Physics, volume 174, number 2, pages 510-551 (December 2001) for more details on B-spline derivative operators and their properties.
Higher order B-spline collocation at the Greville abscissae by Johnson published in Applied Numerical Mathematics, volume 52, number 1, pages 63-75 (January 2005) for information about Greville abscissae.
