Detailed Description

template<typename Scalar, int IndexBase = 0, template< typename > class Primitive = primitive>
class nsctpl_rholut::manufactured_solution< Scalar, IndexBase, Primitive >

Template that, given a primitive function for rho, u, v, w, and T along with a floating point type, evaluates a manufactured solution and the required forcing for the transient, compressible Navier–Stokes equations with a power law viscosity.

Location and time arguments are templated to allow extended precision intermediate computations (followed by truncation) when possible.

A single method for simultaneously computing forcing for all five equations in a conservative formulation at a given location.

That is, computing Q_rho(), Q_rhou(), Q_rhov(), Q_rhow(), and Q_rhoe(). Faster than using those five methods separately because it eliminates redundant computations.

Parameters
[in]xX coordinate at which to evaluate forcing
[in]yY coordinate at which to evaluate forcing
[in]zZ coordinate at which to evaluate forcing
[in]tTime coordinate at which to evaluate forcing
[out]Q_rhoEquivalent to Q_rho(x,y,z,t)
[out]Q_rhouEquivalent to Q_rhou(x,y,z,t)
[out]Q_rhovEquivalent to Q_rhov(x,y,z,t)
[out]Q_rhowEquivalent to Q_rhow(x,y,z,t)
[out]Q_rhoeEquivalent to Q_rhoe(x,y,z,t)
