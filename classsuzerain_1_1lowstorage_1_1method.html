Detailed Description

template<template< typename, typename > class Scheme, typename Element>
class suzerain::lowstorage::method< Scheme, Element >

Given a Scheme and Element type, encapsulates a low storage method behind the method_interface interface using constants.

Template Parameters
SchemeAn essential set of scheme-specific constants usable within the constants class.
Areal- or complex-valued scalar type to be used. constants are returned as the corresponding real type, called component.
See also
smr91 or yang11 for examples of valid Schemes to supply.
