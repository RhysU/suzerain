Detailed Description

Provides implicit operator apply and solve routines for a single wall-normal pencil of state information.

The operator is described in "Hybrid implicit/explicit" treatment within the model document. These routines are meant to be used in conjunction with compute kernels found in rholut.hpp. The logic is coded in C99 to facilitate profiling.

These routines optionally may impose a mostly-implicit Giles nonreflecting boundary condition on the final coefficients corresponding to the upper boundary. When enabled, the routines adjust upper boundary accumulation results according to

\begin{align*} \left(M+\varphi{}L_I^G\right)\hat{V} - \left(M+\varphi{}L\right)\hat{V} &{}=-\ii \varphi{} k_x \, {R^Y}^{-1} \left[V^L S\right]^{-1} \left[P^G C^G\right] \left[V^L S\right] {R^Y} \,M\,\hat{V} \\ &{}- \ii \varphi{} k_z {R^Y}^{-1} \left[V^L S\right]^{-1} \left[P^G B^G\right] \left[V^L S\right] {R^Y} \,M\,\hat{V} \\ &{}- {R^Y}^{-1} \left[V^L S\right]^{-1} \left[P^G \right] \left[V^L S\right] {R^Y} \left(\varphi{}L\hat{V}\right) \end{align*}

provided their a, b, and c parameters are non-NULL. For a valid boundary condition to be in effect, additional conditions must be imposed during the explicit nonlinear Navier–Stokes operator application. See the subsection entitled "Implementation primarily within the linear implicit operator" within Suzerain's perfect gas model document for more details.

Accumulate the linear implicit operator application \(y \leftarrow{} \left(M + \varphi{}L\right) x + \beta{} y\).

The matrix \(L\) is a function of the provided wavenumbers, scenario parameters, and wall-normal reference quantities. The problem size and discrete operators are taken from the provided B-spline workspace w. Input and output state variables must be stride one.

Providing a NULL value for any input and its corresponding output (e.g. in_rho and out_rho) omits the corresponding part of the operator. This may be useful for omitting part of the operator (e.g. the density equation).

Parameters
[in]phiFactor \(\varphi\) used in forming \(M+\varphi{}L\).
[in]kmX direction wavenumber \(k_m = 2\pi{}m/L_x\) (from, for example, suzerain_inorder_wavenumber).
[in]knZ direction wavenumber \(k_n = 2\pi{}n/L_z\) (from, for example, suzerain_inorder_wavenumber).
[in]sScenario parameters used to form the operator.
[in]rReference quantities used to form the operator.
[in]ldStrides between reference quantity values.
[in]wB-spline workspace providing discrete operators.
[in]in_rho_EWall-normal input data for \(\rho{}E\).
[in]in_rho_wWall-normal input data for \(\rho{}w\).
[in]in_rho_vWall-normal input data for \(\rho{}v\).
[in]in_rho_uWall-normal input data for \(\rho{}u\).
[in]in_rhoWall-normal input data for \(\rho{}\).
[in]betaAccumulation scaling factor \(\beta\).
[out]out_rho_EWall-normal output data for \(\rho{}E\).
[out]out_rho_wWall-normal output data for \(\rho{}w\).
[out]out_rho_vWall-normal output data for \(\rho{}v\).
[out]out_rho_uWall-normal output data for \(\rho{}u\).
[out]out_rhoWall-normal output data for \(\rho{}\).

A mostly-implicit Giles nonreflecting boundary condition may optionally be imposed on the final coefficient corresponding to the upper boundary when a, b, and c are non-NULL.

Parameters
[in]aIf NULL, ignored. Set to the 5x5 column major matrix \({R^Y}^{-1} \left[V^L S\right]^{-1} \left[P^G C^G\right] \left[V^L S\right] {R^Y} M \) for upper NRBC.
[in]bIf NULL, ignored. Set to the 5x5 column major matrix \({R^Y}^{-1} \left[V^L S\right]^{-1} \left[P^G B^G\right] \left[V^L S\right] {R^Y}M \) for upper NRBC.
[in]cIf NULL, ignored. Set to the 5x5 column major matrix \({R^Y}^{-1} \left[V^L S\right]^{-1} \left[P^G \right] \left[V^L S\right] {R^Y}\) for upper NRBC.
