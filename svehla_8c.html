◆ suzerain_svehla_air_mu_vs_T()

gsl_spline * suzerain_svehla_air_mu_vs_T ( )

Obtain a lookup table of air's viscosity in Pascal-seconds versus temperature in degrees Kelvin according to Svehla 1962 table IV on page 117.

The returned gsl_spline* can be interrogated using <a href="http://www.gnu.org/software/gsl/manual/html_node/Higher_002dlevel-Interface.html" the usual routines. The return value must be subsequently cleaned up using gsl_spline_free().

Returns
On success, a gsl_spline * for use with gsl_spline_eval(). On failure NULL is returned.
