template<class MultiArray >
bool suzerain::multi_array::is_contiguous ( const MultiArray &  x)

Is the given MultiArray contiguous in memory?

A MultiArray is contiguous when the product(shape(), shape() + dimensionality) equals the distance between the first and last element according to index_bases(), strides() and shape().

Parameters
xMultiArray to check for contiguity.
Returns
True if is contiguous. False otherwise.
