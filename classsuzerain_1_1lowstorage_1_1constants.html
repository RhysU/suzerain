Detailed Description

template<template< typename, typename > class Scheme, typename Component, typename Integer = std::ptrdiff_t>
class suzerain::lowstorage::constants< Scheme, Component, Integer >

Compute redundant information for an method_interface given essential, scheme-specific constants.

The Scheme parameter must be a templated, static-only struct encapsulating a small number of independent pieces of information:

name
A human-readable name for the scheme
substeps
Number of substeps within the scheme
evmaxmag_real
The maximum purely real stable eigenvalue magnitude
evmaxmag_imag
The maximum purely imaginary stable eigenvalue magnitude
alpha_numerator
The numerators for the \(\alpha_i\) written using denominator
beta_numerator
The numerators for the \(\beta_i\) written using denominator
gamma_numerator
The numerators for the \(\gamma_i\) written using denominator
denominator
The least common multiple of all denominators appearing within \(\alpha\), \(\beta\), or \(\gamma\).

Numerators and denominators are tracked separately to permit performing integer operations wherever possible. This permits maintaining full precision constants via very simple rational operations. All computed results may be accessed as if contained in static arrays. For example, eta[1] or iota_beta[2].

Template Parameters
SchemeA class encapsulating the minimum constants required to describe a low storage scheme.
ComponentReal-valued type for which constants are returned.
IntegerSigned integer type used for indexing and computation.

method_interface for a full definition of the constants involved.
