Detailed Description

A Largo-related convenience class for manipulating double-valued buffers containing \(\rho\), \(\rho{}u\), \(\rho{}v\), \(\rho{}w\), \(\rho{}E\), and \(p\) in that order.

Largo-based slow growth computations require conserved state packed in this fashion. Pressure \(p\) is wholly redundant but Largo requires it for certain slow growth forcing models.
