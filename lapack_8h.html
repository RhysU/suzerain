Detailed Description

Wraps external LAPACK routines necessary for Suzerain. Provided to insulate the library from potential variations in type signatures as well as to consolidate all Fortran-from-C parameter differences.

See also
A LAPACK reference for more details.

Determines machine parameters for floating-point arithmetic.

The input parameter cmach should specify which of the following values is desired:

E, e
eps, relative machine precision
S, s
sfmin, safe minimum, such that 1/sfmin does not overflow
B, b
base, base of the machine
P, p
eps*base
N, n
t, number of (base) digits in the mantissa
R, r
rnd, 1.0 when rounding occurs in addition, 0.0 otherwise
M, m
emin, minimum exponent before (gradual) underflow
U, u
rmin, underflow threshold - base**(emin-1)
L, l
emax, largest exponent before overflow
O, o
rmax, overflow threshold - (base**emax)*(1-eps)
Parameters
cmachThe desired machine-specific quantity.
Returns
the value requested per parameter cmach.

Compute the LUP decomposition of a general banded matrix using LAPACK's gbtrf.

Stores the results back into the same matrix. Note that the banded matrix storage must have kl extra superdiagonals available to handle the factorization fill in.

Parameters
mNumber of rows in matrix ab.
nNumber of columns in matrix ab.
klNumber of subdiagonals in band storage of ab.
kuNumber of superdiagonals in band storage of ab.
abGeneral band storage of the matrix to factor.
ldabLeading dimension of ab.
ipivPivot matrix computed in the decomposition.
Returns
Zero on successful execution. Nonzero otherwise.
See also
gbtrs for how to solve a linear system once you have decomposed the matrix.
A LAPACK reference for the lda >= 2*kl + ku + 1 storage requirement and the resulting factored storage format.

Solve \( AX = B \) using the previously LUP decomposed general band matrix \( A \) and LAPACK's gbtrs.

Transposes of \( A \) can be taken using the trans parameter.

Parameters
transOne of 'N', 'T', or 'C' for no transpose, a transpose, or a conjugate transpose, respectively.
nNumber of rows and columns in matrix ab.
klNumber of subdiagonals in band storage of ab.
kuNumber of superdiagonals in nonfactored matrix ab. Note this is not the number of superdiagonals in the storage format of ab, but rather the number of superdiagonals required to store the non-factored matrix ab. This is odd.
nrhsNumber of right hand sides, or columns, in b.
abGeneral band storage of the matrix to factor.
ldabLeading dimension of ab.
ipivPivot matrix already computed in the decomposition.
bMatrix \( B \) containing right hand sides on invocation and solutions on return.
ldbLeading dimension of matrix b.
Returns
Zero on successful execution. Nonzero otherwise.
See also
gbtrf for how to decompose the matrix \( A \).
