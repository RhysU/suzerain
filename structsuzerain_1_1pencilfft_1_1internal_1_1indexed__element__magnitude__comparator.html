Detailed Description

template<class RandomAccessIterator>
struct suzerain::pencilfft::internal::indexed_element_magnitude_comparator< RandomAccessIterator >

Compares indices based on element magnitude comparison from some underlying RandomAccessIterator.

Element magnitude is calculated using std::abs.
