Detailed Description

template<std::size_t Dim, typename Element>
class suzerain::contiguous_state< Dim, Element >

A state class storing elements with the first index slowest followed by the other indices in Fortran order.

The indexing is indented to store some number of non-interleaved scalars in the first index with dimensionality Dim spread across the remaining indices.

Template Parameters
DimNumber of dimensions
ElementType of elements to store
See also
storage_order_type for more details on the storage used.
