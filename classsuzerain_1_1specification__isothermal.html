Detailed Description

Holds parameters for specifying simple isothermal boundary conditions on the \(y=0\) and \(y=L_y\) planes.

These conditions include no-slip walls, transpiring walls, and constant freestream boundaries. Code consuming these values may treat NaN as a do-not-enforce-constraint flag.

Specify two different temperatures, wall blowing velocities, and associated streamwise velocities for a single "diluter" species.

NaN may be specified for lower_v or upper_v to indicate that the boundary-normal velocity should be determined by some other means. Such usage requires auxiliary information (e.g. an instantaneous mean velocity at the boundary) in conjunction with a boundary condition implementation (e.g. operator_mass_isothermal).
