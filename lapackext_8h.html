Detailed Description

LAPACK-like extensions built atop LAPACK, the BLAS, and/or on custom coded loops. Some of these extensions resemble newer LAPACK features which have not trickled down to banded matrices from general matrices.

Compute the solution to a banded system of linear equations \(A x = b \) using single precision LU factorization followed by double precision iterative refinement.

The overall functionality is an extension of the capability of LAPACK's DSGESV but written for general banded matrices. The approach follows DSGESV which is based on the DGESIRSV algorithm presented in June 2006 as LAWN 175: Exploiting the Performance of 32 bit Floating Point Arithmetic in Obtaining 64 bit Accuracy (Revisiting Iterative Refinement for Linear Systems) by Langou et al. Unlike their algorithm, this routine

  1. permits the user to provide a preexisting single or double precision factorization,
  2. returns the single or double precision factorization for subsequent reuse,
  3. permits the caller to provide the Frobenius norm of \(A\),
  4. assumes only one right hand side is of interest (above changes, however, permit efficient repeated invocation),
  5. requires that matrix storage is contiguous (i.e. ldab == kl + ku + 1, ldafb == 2*kl + ku + 1), for reasons of cache-friendliness,
  6. performs precision demotion and promotion in-place for reasons of cache-friendliness,
  7. performs iterative refinement after the double-precision fallback LU factorization if the direct solution fails to meet the solution tolerance,
  8. permits the user to scale the required tolerance by some amount to accommodate situations where lower precision results are acceptable,
  9. requires the user to specify the maximum number of refinements to attempt (Langou et al. suggested thirty, ?gbrfsx suggests up to one hundred in aggressive circumstances like providing approximate factorizations),
  10. makes accessible the number iterative refinements attempted,
  11. and makes accessible the final residual vector and residual.

All in all, these changes are designed to permit combining single precision factorization along with possibly using approximate factorizations and refinement as a means to Newton iteration. The consistent error bound testing in either single precision factorization or double precision factorization is intended to permit the results to be indistinguishable regardless of solution method.

Parameters
[in,out]factOn input, 'N' if factorization must be performed; 'S' if a single precision factorization is provided in afb and ipiv; 'D' if a double precision factorization is provided in afb and ipiv. On output, either 'S' or 'D' indicating which factorization precision has been returned in afb and ipiv.
[in,out]apprxOn input, if fact is 'S' or 'D' and apprx is nonzero, assume the factorization provided in afb and ipiv is \( LUP = A + \Delta{}A\) for some perturbation \( \Delta{}A \). If the provided factorization fails to deliver adequate convergence as described under aiter, ab will be factorized and apprx set to zero on return. If fact is 'N' on input, apprx is ignored and set to zero on return.
[in]aiterAt most aiter refinement steps will be attempted before it can be confirmed that the residual is decaying by a factor of two at each step. Parameter aiter is used during mixed-precision refinements and during double-precision refinements when apprx is nonzero.
[in]transIf 'N' solve \(A x = b\). If 'T' solve \(A^\top x = b\). If 'C' solve \(A^H x = b\).
[in]nNumber of rows and columns in \( A \).
[in]klNumber of subdiagonals in \( A \).
[in]kuNumber of superdiagonals in \( A \).
[in]abDouble precision matrix in banded storage of dimension (ldab == kl + ku + 1, n).
[in,out]afrobThe Frobenius norm of \( A \). If negative on entry and tolsc is strictly positive, the norm is computed and returned to permit caching the result. Otherwise, afrob is not modified.
[in,out]afbSingle or double precision LU factorization of \(A\) of dimension (ldafb == 2*kl + ku + 1, n). Whether a single or double precision result is returned is communicated by fact on return.
[in,out]ipivLU pivoting information for the factorization in afb of dimension n.
[in]bRight hand side \( b \) of length n.
[out]xComputed solution \( x \) of length n.
[in,out]siterOn input, the maximum number of single precision iterative refinements to attempt. Zero specifies no single precision refinements are to occur. If negative, no single precision factorization or solve will be formed and double precision processing occurs. On output, the number of such refinements performed.
[in,out]diterOn input, the maximum number of double precision iterative refinements to attempt. Zero specifies no double precision refinements are to occur. If negative, no double precision factorization or solve will be performed. On output, the number of such refinements performed.
[in,out]tolscOn input, a nonnegative multiplicative factor used to scale the Langou et al. tolerance \( \sqrt{n} \text{eps} \|A\|_\text{Fro} \|x\|_2 \) against which the residual is compared as a stopping criterion. The recommended value from Langou et al is 1.0 to regain full accuracy as measured per backward stability. The special value 0.0 can be provided to specify that double precision machine epsilon should be used which, in conjunction with siter < 0, makes the refinement process act like LAPACK's ?gbrfs. On output, the fraction of the tolerance represented by the returned solution. Values greater than one indicate the desired tolerance could not be met.
[out]rSolution residual \( b - A x \).
[out]res2-norm of the residual. That is, \(\|b - A x\|_2\).

One or both of siter or diter must be nonnegative on entry.

If tolsc is identically zero, siter should be strictly negative. This requirement is not enforced, but it is madness to think that mixed-precision iterative refinement will provide residuals better than those returned by a full-precision procedure.

Returns
Zero on successful execution. Nonzero otherwise. Errors related to the i-th argument are indicated by a return value of -i.
