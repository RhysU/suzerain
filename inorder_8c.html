Detailed Description

Provides utilities for manipulating one dimensional discrete Fourier transform coefficients stored "in-order".

From href="http://www.fftw.org/fftw3_doc/One_002dDimensional-DFTs-of-Real-Data.html">FFTW's documentation: "...the <tt>k</tt>-th output corresponds to the frequency <tt>k/n</tt> (or <tt>k/T</tt>, where <tt>T</tt> is your total sampling period). For those who like to think in terms of positive and negative frequencies, this means that the positive frequencies are stored in the first half of the output and the negative frequencies are stored in backwards order in the second half of the output. (The frequency <tt>-k/n</tt> is the same as the frequency <tt>(n-k)/n</tt>.)"

The following concepts are used throughout these routine descriptions. They are defined assuming one is working with a one-dimensional discrete Fourier transform (DFT) data of length N:

index
The indices are the nonnegative integers 0, 1, ..., N-1. These are the usual C indices used to access an array of length N.
wavenumber
The wavenumbers are the integers (-N+1)/2, ..., -1, 0, 1, ..., N/2 such that \(k_i = \frac{2\pi{}i}{L}\) ranges over the frequencies supported on a domain of length \(L\).
range
A range [a,b) contains the integers a, a+1, ..., b-2, b-1 assuming b > a. For b == a the range contains nothing and is said to be empty.

To make these concepts concrete, for N = 8 the indices run from 0 to 7, inclusive. This is index range [0,8). The wavenumbers corresponding to these indices are 0, 1, 2, 3, 4, -3, -2, -1.

Translate the index range [tb, te) from a length T DFT to a length S DFT.

In-order storage for T != S implies the index range may be broken into at most two contiguous ranges.

More specifically, when ignoring wavenumbers not found in a length S DFT, the data kept in [tb,te) is equivalent to [tb1,te1) and [tb2,te2). Further, the range [tb1,te1) contains data equivalent to [sb1,se1) and [tb2,te2) contains data equivalent to [sb2,se2).

Such information could be used to copy data prepared for DFTs of disparate lengths. Two steps would be necessary. First, a copy from [sb1,se1) to [tb1,te1). Second, a copy from [sb2,se2) to [tb2,te2). Either copy may be of zero length.
