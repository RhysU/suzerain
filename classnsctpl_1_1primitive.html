Detailed Description

template<typename Scalar>
class nsctpl::primitive< Scalar >

Class providing operations for evaluating an analytical solution at a given location and time.

The solution is of the form 

*       a_0                                         *cos(f_0 *t + g_0 )
*     + a_x  * cos(b_x *x + c_x )                   *cos(f_x *t + g_x )
*     + a_xy * cos(b_xy*x + c_xy)*cos(d_xy*y + e_xy)*cos(f_xy*t + g_xy)
*     + a_xz * cos(b_xz*x + c_xz)*cos(d_xz*z + e_xz)*cos(f_xz*t + g_xz)
*     + a_y  * cos(b_y *y + c_y )                   *cos(f_y *t + g_y )
*     + a_yz * cos(b_yz*y + c_yz)*cos(d_yz*z + e_yz)*cos(f_yz*t + g_yz)
*     + a_z  * cos(b_z *z + c_z )                   *cos(f_z *t + g_z )
*

The member method names are non-traditional but permitted by the language standards and well-aligned with mathematical notation. Location and time arguments are templated to allow extended precision intermediate computations (followed by truncation) when possible.

The foreach_parameter() member allows invoking an operation on each solution parameter to aid parameter registration, initialization, or output. Parameters may have an infix name added for use with foreach_parameter(). For example, setting the name 'phi' will cause foreach_parameter() to report names like 'a_phix'.
