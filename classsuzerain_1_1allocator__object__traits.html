Detailed Description

template<typename T>
class suzerain::allocator_object_traits< T >

A generic set of object traits for the policy driven allocator.

Necessary since some classes may overload operator&. Classes which overload this operator should provide a specialization of allocator_object_traits.

See also
Lai Shiaw San Kent's article C++ Standard Allocator, An Introduction and Implementation for more information.
