inlinestatic

Given points a, b, x, and y under the assumption a <= b, do intervals ab and xy overlap and if so what is the order-matching interval? Order-matching means an interval with endpoints (p, q) such that p < q whenever x <= y and p > q whenever x > y.

Parameters
[in]aLeft endpoint on the first interval
[in]bRight endpoint on the first interval
[in]xEndpoint on the second interval
[in]yAnother on the second interval
[out]lif method returns true, set to be the lower endpoint of the order-matching intersection.
[out]uif method returns true, set to be the upper endpoint of the order-matching intersection.
Returns
True if the segments intersect. False otherwise.
