Detailed Description

template<typename T, class ArenaAllocator = ::std::allocator<T>, class Policy = coalescing_pool_policy<T>>
class suzerain::coalescing_pool< T, ArenaAllocator, Policy >::blocks

A contiguous sequence of blocks acquired from a coalescing_pool.

Each instance logically represents the memory spanned by those contiguous blocks.
