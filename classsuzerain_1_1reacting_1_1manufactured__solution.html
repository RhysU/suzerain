Detailed Description

Manufactured solution employed throughout the reacting flow code.

By subclassing support::definition_base we can pass an instance to program_options::add_definition method to permit modifying parameters via the command line.

None of alpha, beta, gamma, Ma, Pr, Re or Lx, Ly, Lz are modified when used in this fashion. The former group will need to be synced using match() and the later group using match(const specification_grid&).
