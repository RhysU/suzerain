Detailed Description

Encapsulates an operator and a LU decomposition from a real-valued linear combination of derivative operators.

Callers obtain a workspace using suzerain_bsplineop_lu_alloc() and release it using suzerain_bsplineop_lu_free().

As manipulating an unfactored operator is easiest using the unfactored kl and ku, and as LAPACK's GBTRF and GBTRS are written using the unfactored values of kl and ku, we do too. The unfactored transpose of the operator uses column-major band storage per GBTRF's AB "on entry" documentation. After factorization, the factorization of the transposed operator is stored per GBTRS's "on entry" documentation.

See also
suzerain_bsplineop_luz_workspace for manipulating the complex-valued case.

◆ A_T

double* suzerain_bsplineop_lu_workspace::A_T

Raw data storage for the unfactored and factored operator transposes.

The transpose of the operator is stored according to LAPACK GBTRF conventions regarding kl, ku, ld, and n. In particular, this means A + kl is the starting general band storage location for the transpose of the unfactored operator.
