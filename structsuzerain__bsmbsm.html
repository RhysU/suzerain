Detailed Description

Storage details for a banded square matrix with banded submatrices (BSMBSM).

No data is stored within this POD type. However, the struct contains redundant data which should be computed consistently using suzerain_bsmbsm_construct().

See also
bsmbsm.h for full details on BSMBSMs.
