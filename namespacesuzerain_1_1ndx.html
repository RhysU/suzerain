template<typename Index >
Index suzerain::ndx::rho_ ( const Index  i)

Compute the index of the (zero-indexed) i-th species partial density for i > 0.

Because the diluter species partial density if not tracked, i > 0 is required. Notice neither identifier nor description is provided for these indices.

Template Parameters

Parameters
iZero-indexed species of interest.
Returns
