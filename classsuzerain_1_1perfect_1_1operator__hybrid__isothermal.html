Detailed Description

A hybrid implicit/explicit operator that providing isothermal wall conditions and possibly a nonreflecting freestream.

It requires interoperation with operator_nonlinear, set on member N, via operator_common_block. The operator includes, by way of subclassing treatment_nonreflecting, the ability to provide nonreflecting boundary conditions when necessary.

Applies Giles conditions delegating most processing to N.

That is, compute

\[ \underbrace{ {R^Y}^{-1} \left[V^L S\right]^{-1} \left( \chi^{-1} \left( \ii k_x \left[P^G C^G\right] + \ii k_z \left[P^G B^G\right] \right) \left[V^L S\right] R^Y M \hat{V} + \left(I - P^G\right) \left[V^L S\right] R^Y N(\hat{V}) \right) }_{N_E^G\left(\hat{V}\right)} \]

assuming that N implements \(N(\hat{V})\).

Uses, and on substep_index == 0 updates, all of

  1. VL_S_RY
  2. PG_BG_VL_S_RY
  3. PG_CG_VL_S_RY
  4. PG_VL_S_RY
  5. inv_VL_S_RY

during invocation.

Invert \(M+\phi{}L\) in-place for scalar \(\phi\).

That is, \(\mbox{state}\leftarrow{}\left(M+\phi{}L\right)^{-1}\mbox{state}\).

Low storage timestepping schemes do not make make use of ic0. It is intended as a problem-specific hook for implementing integral constraints. When ic0 is non-NULL, some portion of the inverse operator also must be applied to some portion of the data in ic0. That is, \(\mbox{ic0} \leftarrow{} \left(M+\phi{}L\right)^{-1} \mbox{ic0}\). In a mixed Fourier discretiation, a mean integral constraint is applied via applying the inverse `‘zero-zero’' operator and hence the name. The exact behavior is subclass dependent.

Parameters
phiScale factor \(\phi\) to use.
stateState vector on which to apply the operator.
methodThe low storage scheme being used
delta_tThe size of the currently active time step.
substep_indexThe (zero-indexed) time stepper substep index.
ic0Additional state, often used for imposing integral constraints, which is ignored when NULL.
