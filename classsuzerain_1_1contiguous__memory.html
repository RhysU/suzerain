Detailed Description

template<typename Element, typename Allocator = std::allocator<Element>>
class suzerain::contiguous_memory< Element, Allocator >

At construction, allocates a contiguous block of memory containing Elements allocated using Allocator.

At destruction the memory is freed. This seemingly goofy class is useful because it can be inherited from as a way to workaround base class versus member construction time semantics.

Template Parameters
ElementType of elements to allocate.
AllocatorAllocator to use for memory operations.
