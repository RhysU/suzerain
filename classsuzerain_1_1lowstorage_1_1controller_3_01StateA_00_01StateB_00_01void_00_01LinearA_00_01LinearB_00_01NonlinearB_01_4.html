Detailed Description

template<typename StateA, typename StateB, typename LinearA, typename LinearB, typename NonlinearB>
class suzerain::lowstorage::controller< StateA, StateB, void, LinearA, LinearB, NonlinearB >

A partial specialization of the controller template for the case when default delta_t_reducer behavior is desired.

Empty base class optimization eliminates the delta_t_reducer instance overhead.

Register a one-time callback to be invoked during advance() when the simulation reaches what_t or what_nt, whichever comes first.

The argument callback must be a function or functor compatible with boost::function<StopType (TimeType, StepType)>. When invoked, the first argument will contain the current_t() and the second argument will contain current_nt(). The callback must return true if the controller should continue advancing. If the callback returns false, the controller will immediately stop advancing time.

Parameters
what_tThe simulation time to perform the callback. The provided value must be larger than current_t(). Use forever_t() if you want no callbacks based on the current simulation time.
what_ntThe simulation time step to perform the callback. The provided value must be larger than current_nt(). Use forever_nt() if you want no callbacks based on the current time step.
callbackThe callback to invoke.

Specifying both what_t == forever_t() and what_nt == forever_nt() causes the callback to be discarded.

See also
Boost.Ref if you need to provide a stateful or noncopyable functor as the callback argument.

Register a periodic callback to be invoked during advance().

As the controller marches the simulation, callback will be invoked every_dt time steps or after every_t simulation time passes, whichever comes first. The first such invocation will occur no more than first_dt time units after this registration call.

Parameters
first_dtThe maximum simulation time duration before the first callback. Use forever_t() if you want no callbacks based on the current simulation time.
every_dtThe maximum simulation time duration between callbacks. Use forever_t() if you want no callbacks based on the current simulation time.
every_ntThe simulation time step count between callbacks. Use forever_nt() if you want no callbacks based on the current time step.
callbackThe callback to invoke. See add_callback() for a discussion of this argument's semantics.

Specifying every_dt == forever_t() and every_nt == forever_nt() causes the callback to be discarded. If a once-only callback is desired, instead use add_callback.

Advance the simulation in time using the time stepper set at construction time and perform required callbacks along the way.

The simulation will advance until either current_t() reaches final_t or current_nt() reaches final_nt, whichever comes first. If any physically-determined time step is smaller than min_dt() or any registered callback returns false, the controller will immediately stop. The former condition can be diagnosed by comparing current_dt() to min_dt(). The controller will also stop if it encounters a step size for which isfinite is false.

Parameters
final_tMaximum simulation time. If you want to advance some relative amount dt, try supplying current_t() + dt. For unlimited simulation time, use forever_t().
final_ntMaximum simulation time step. If you want to advance some relative step count nt, try supplying current_nt() + nt. For unlimited time step counts, use forever_nt().
Returns
True if the controller completed the request successfully. False if the controller aborted for some reason.
See also
The method step() for an easy way to specify a fixed number of time steps.
