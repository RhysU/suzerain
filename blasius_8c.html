Detailed Description

Presents a Blasius laminar flow profile curve fit.

A nice discussion of the solution and its properties appears in section 9.3 of Fluid Mechanics by Kundu, Cohen, and Dowling (ISBN 9780123821003).

Throughout these routines \(x\) is the streamwise location downstream from a flat plate edge and \(y\) is the wall-normal distance from the plate. The local Reynolds number \(\mbox{Re}_x = \frac{u_\infty}{\nu x}\) scales the similarity coordinate \(\eta = y \sqrt{\mbox{Re}_x}\). Generally, values greater than \(10^6\) are physically invalid as the flow should be turbulent in that regime.

◆ suzerain_blasius_u()

gsl_spline * suzerain_blasius_u ( const double  Re_x)

Obtain a Blasius profile fit producing nondimensional \(u / u_\infty\) given \(y = \eta / \sqrt{\mbox{Re}_x}\).

The data is from suzerain_blasius_extended_fp and suzerain_blasius_extended_eta.

The returned gsl_spline* can be interrogated using the usual routines. The return value must be subsequently cleaned up using gsl_spline_free().

Parameters
Re_xLocal Reynolds number \(\mbox{Re}_x\).
Returns
On success, a gsl_spline * for use with gsl_spline_eval(). On failure NULL is returned.

◆ suzerain_blasius_T()

gsl_spline * suzerain_blasius_T ( const double  Re_x,
const double  Pr 
)

Obtain a Blasius profile fit producing nondimensional \(\frac{T - T_w}{T_\infty - T_w}\) given \(y = \eta / \sqrt{\mbox{Re}_x \mbox{Pr} }\).

The data used is identical to suzerain_blasius_u except that it is rescaled to produce a thermal boundary layer given similarity assumptions employing a constant Prandtl number.

The returned gsl_spline* can be interrogated using the usual routines. The return value must be subsequently cleaned up using gsl_spline_free().

Parameters
Re_xLocal Reynolds number \(\mbox{Re}_x\).
PrConstant Prandtl number \(\mbox{Pr}\).
Returns
On success, a gsl_spline * for use with gsl_spline_eval(). On failure NULL is returned.
